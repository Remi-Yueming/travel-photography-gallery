## About
This is my little corner for the places I've been and the moments I don't want to lose.

Instead of keeping travel photos buried in my camera roll, I wanted to give them a place — connecting each photograph with the journey, place, and memory behind it.

It's also an easy way to share a trip with friends: the places I loved, the ones I'd recommend, and the little moments that made each journey memorable.

## Places

🇮🇩 Bali, Indonesia  
🇹🇭 Chiang Rai & Pattaya, Thailand  
🇻🇳 Phu Quoc & Ho Chi Minh City, Vietnam  

## About the Project

This website is my first website projects, exploring how photography and storytelling can come together. 
Rather than building a traditional photography portfolio, I wanted to create something closer to a **digital travel journal** — personal enough to preserve memories, but simple enough to share with friends when they ask, *“Where did you go?”* or *“What would you recommend?”*
### Built with

- 📷 Original photography
- ✍️ Personal travel notes & recommendations
- 🤖 AI-assisted development
